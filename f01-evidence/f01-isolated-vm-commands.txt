Do not run them on a machine that already has a real Negm Lodaing install, desktop shortcut, or production HKCU key.

8. Restore the original uninstall.cmd from the first install only if you still have its bytes. Then run uninstall.cmd and confirm exit 0 or 4 according to shortcut policy, and that outside-user.txt is byte-for-byte unchanged.
